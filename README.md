## 🎯 Objetivo Geral

> *Desenvolver e documentar aplicações para desktop com acesso a banco de dados.*

Este projeto visa consolidar os conhecimentos práticos e teóricos de engenharia de software, passando por todas as fases do ciclo de vida da aplicação, desde a concepção da ideia até os testes finais.

---

## 📚 Ementa (O que é abordado neste projeto)

O desenvolvimento deste software segue os seguintes pilares:

- [x] 🔍 **Definição de problemas:** Identificação e delimitação do escopo do sistema.
- [x] ⚙️ **Processo de Desenvolvimento:** Aplicação de metodologias ágeis/tradicionais de software.
- [x] 📋 **Análise de requisitos:** Levantamento de requisitos funcionais e não funcionais.
- [x] 📐 **Modelagem:** Criação de diagramas (UML, Casos de Uso, Classes, etc).
- [x] 🏗️ **Projeto arquitetural:** Definição da arquitetura do sistema e banco de dados.
- [x] 💻 **Desenvolvimento Desktop:** Criação da interface de usuário e regras de negócio.
- [x] 🛠️ **Implementação:** Codificação do software.
- [x] 🧪 **Teste de aplicação:** Validação de funcionalidades e prevenção de bugs.
