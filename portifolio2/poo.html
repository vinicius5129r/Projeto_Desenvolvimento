Programação Orientada a Objetos (POO)

Paradigma focado em representar o mundo real através de Objetos, Classes e seus relacionamentos.

⬅ Voltar para o Início
Teoria, Estruturada vs POO e Variáveis vs Objetos

Conceito: Na programação estruturada, o código é uma sequência de funções (ações). Na POO, o código é um conjunto de Objetos que interagem entre si. Variáveis comuns guardam apenas um valor (ex: int idade = 20;). Objetos guardam Atributos (características) e Métodos (ações/comportamentos) juntos.

Pilares da POO

Conceito: A base da POO se resume em 4 regras fundamentais:

  • Abstração: Pegar algo do mundo real e trazer só o que importa para o código.
  • Encapsulamento: Proteger os dados, escondendo o que não precisa ser visto de fora.
  • Herança: Uma classe "filha" herda características de uma classe "mãe".
  • Polimorfismo: Objetos diferentes podem responder ao mesmo comando de formas diferentes.
Classe Vazia e Atributos

Conceito: A Classe é o molde (a planta da casa). O Objeto é a casa construída. Atributos são as características desse molde.

Exemplo:

// Criando a classe (O Molde)
public class Carro {
    // Atributos (Características)
    String cor;
    String modelo;
    int ano;
}
Métodos (Funções) e Construtor

Conceito: Métodos são as ações que o objeto faz. O Construtor é um método especial chamado automaticamente quando o objeto nasce (é instanciado com new).

Exemplo:

public class Carro {
    String modelo;

    // Método Construtor (Tem o mesmo nome da classe)
    public Carro(String modeloEscolhido) {
        this.modelo = modeloEscolhido;
    }

    // Método comum (Ação)
    public void acelerar() {
        System.out.println("Vrum vrum!");
    }
}

// Criando o objeto na prática:
Carro meuCarro = new Carro("Fusca");
meuCarro.acelerar();
Encapsulamento, Getters e Setters

Conceito: Para proteger os dados (Encapsulamento), deixamos os atributos como private (privados). Para acessá-los ou alterá-los de forma segura, usamos métodos públicos chamados Get (pegar) e Set (alterar).

Exemplo:

public class ContaBancaria {
    // Privado: Ninguém de fora mexe direto aqui
    private double saldo;

    // Setter: Regra para alterar o saldo
    public void setSaldo(double valor) {
        if(valor > 0) {
            this.saldo = valor;
        }
    }

    // Getter: Regra para ver o saldo
    public double getSaldo() {
        return this.saldo;
    }
}
Herança

Conceito: Permite criar uma nova classe aproveitando o código de uma classe que já existe. Usa-se a palavra extends.

Exemplo:

// Classe Mãe
public class Animal {
    public void comer() {
        System.out.println("Comendo...");
    }
}

// Classe Filha (Herda de Animal)
public class Cachorro extends Animal {
    public void latir() {
        System.out.println("Au au!");
    }
}
Polimorfismo

Conceito: "Muitas formas". É quando a classe filha reescreve (sobrescreve) um método da classe mãe para fazer a mesma ação, mas do seu próprio jeito.

Exemplo:

public class Animal {
    public void fazerSom() {
        System.out.println("Som de animal");
    }
}

public class Gato extends Animal {
    // Reescrevendo o método da mãe
    @Override
    public void fazerSom() {
        System.out.println("Miau!");
    }
}
Bibliotecas

Conceito: Bibliotecas são pacotes de códigos prontos feitos por outros programadores que importamos para facilitar a vida.
