Introdução, Lógica e Diagrama de Blocos

Conceito: Lógica é a organização do pensamento para resolver um problema (Algoritmo). O computador executa passos em sequência.

Diagrama de Blocos: Representação visual do algoritmo usando formas geométricas (ex: losango para decisão, retângulo para processamento).

Paradigmas: Estruturada (foco em funções/sequência) vs Orientada a Objetos (foco em objetos do mundo real).

Variáveis, Constantes e Operadores

Conceito: Variável guarda um valor que pode mudar. Constante guarda um valor fixo.

Operadores: Aritméticos (+, -, *, /) e Lógicos (E, OU, NÃO). 

algoritmo "ExemploVariaveis"
var
   idade: inteiro
   nome: caractere
   PI: real // Constante
inicio
   idade <- 20
   nome <- "Maria"
   PI <- 3.14
   escreval("O nome é: ", nome)
fimalgoritmo
Estruturas de Decisão (Se / Escolha)

Conceito: O programa toma caminhos diferentes dependendo de uma condição (Lógica Booleana). 

// Estrutura SE / SENAO
se (idade >= 18) entao
   escreval("Maior de idade")
senao
   escreval("Menor de idade")
fimse

// Estrutura ESCOLHA / CASO
escolha (opcao)
   caso 1: escreval("Você escolheu 1")
   outrocaso: escreval("Opção inválida")
fimescolha
Estruturas de Repetição (Enquanto / Repita)
  • Enquanto (Teste no início): Só entra no laço se a condição for verdadeira.
  • Repita (Teste no fim): Executa pelo menos uma vez antes de testar a condição. 
contador <- 1
enquanto (contador <= 5) faca
   escreval(contador)
   contador <- contador + 1
fimenquanto
Vetores e Matrizes

Vetor: Unidimensional (uma linha, como uma lista).
Matriz: Bidimensional (linhas e colunas, como uma tabela). 

var
   notas: vetor [1..5] de real
   tabuleiro: vetor [1..3, 1..3] de inteiro
inicio
   notas[1] <- 8.5
   tabuleiro[1, 2] <- 9
fimalgoritmo
