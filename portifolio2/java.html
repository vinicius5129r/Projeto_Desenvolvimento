Linguagem de Programação (Java Avançado)

Aprofundamento na linguagem Java, estruturas de controle, coleções, versionamento e conexão com Banco de Dados.

⬅ Voltar para o Início
Variáveis, Escopo e Operadores

Tipos Primitivos: int, double, boolean, char.

Escopo: Variável local só existe dentro do bloco. Variável global (atributo) pode ser vista por toda a classe.

Operadores: Aritméticos (+ - * / %), Relacionais (== != > < >= <=) e Lógicos (&&, ||).

Estruturas de Seleção e Repetição

Seleção: if/else e switch/case.

Repetição: for, while e do/while. 

for (int i = 1; i <= 5; i++) {
    System.out.println("Contagem: " + i);
}
Vetores (Arrays)

Conceito: Estrutura de tamanho FIXO. Índice começa em 0. 

int[] numeros = new int[3];
numeros[0] = 10;
System.out.println(numeros[0]);
Funções e Passagem de Parâmetros

Conceito: Métodos com void (não retornam) ou com tipo de retorno (int, String, etc). 

public int somar(int a, int b) {
    return a + b;
}
Collections, Autoboxing e Ordenação

Collections: Listas dinâmicas como ArrayList. 

ArrayList<String> nomes = new ArrayList<>();
nomes.add("Zeca");
Collections.sort(nomes);
Versionamento de Código (Git)

Comandos: git init, git add ., git commit -m "msg", git push.

Conexão com Banco de Dados (JDBC) 
String url = "jdbc:mysql://localhost:3306/meubanco";
Connection conexao = DriverManager.getConnection(url, "root", "123");
