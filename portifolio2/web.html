Fundamentos de Desenvolvimento Web

Base teórica e prática sobre a web, estruturação com HTML e estilização com CSS.

⬅ Voltar para o Início
Internet e Arquitetura Cliente-Servidor

Conceito: A Internet é a rede física. A Web é o serviço que roda nela. A arquitetura funciona com um Cliente (navegador) pedindo informações para um Servidor (computador que hospeda o site).

2 Níveis: Cliente direto no Servidor. 3 Níveis: Cliente -> Servidor de Aplicação -> Banco de Dados.

Introdução ao HTML e DOM

Conceito: HTML não é linguagem de programação, é marcação. O DOM é a árvore que o navegador cria para ler o HTML.

Exemplo de Estrutura Básica:

<!doctype html> 
<html lang="pt_br">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <h1>Olá mundo!</h1>
    <p>Essa é a estrutura base html-5</p>
  </body>
</html>
Listas Ordenadas e Não Ordenadas

Conceito: Usadas para organizar informações. <ul> para listas com bolinhas, <ol> para listas numeradas.

Exemplo:

<ul>
    <li>Item sem número</li>
</ul>

<ol>
    <li>Primeiro passo</li>
    <li>Segundo passo</li>
</ol>
Tabulação (Tabelas)

Conceito: Criação de tabelas de dados usando linhas (tr) e colunas/células (td).

Exemplo:

<table border="1">
    <tr>
        <th>Nome</th>
        <th>Idade</th>
    </tr>
    <tr>
        <td>João</td>
        <td>25</td>
    </tr>
</table>
Mídias e Hiperlinks

Conceito: Como inserir imagens, vídeos e criar links para outras páginas.

Exemplo:

<!-- Imagem -->
<img src="foto.jpg" alt="Descrição da foto">

<!-- Link -->
<a href="https://google.com">Ir para o Google</a>

<!-- Vídeo -->
<video controls>
    <source src="video.mp4" type="video/mp4">
</video>
CSS e Box Model

Conceito: CSS estiliza a página. O Box Model diz que todo elemento é uma caixa com: Margin (espaço fora), Border (borda), Padding (espaço dentro) e o Conteúdo.

Exemplo:

/* Seleciona todos os parágrafos */
p {
    color: blue;
    margin: 20px; /* Afasta dos outros elementos */
    padding: 10px; /* Espaço interno */
    border: 1px solid black;
    display: block; /* Ocupa a linha toda */
}
Flexbox

Conceito: Sistema de layout unidimensional (linha ou coluna) para alinhar itens facilmente.

Exemplo:

.container-pai {
    display: flex;
    justify-content: center; /* Centraliza na horizontal */
    align-items: center; /* Centraliza na vertical */
    gap: 10px; /* Espaço entre os filhos */
}
Formulários

Conceito: Capturar dados do usuário.

Exemplo:

<form>
    <label for="nome">Seu Nome:</label>
    <input type="text" id="nome" placeholder="Digite aqui">
    <button type="submit">Enviar</button>
</form>
Grid System

Conceito: Sistema de layout bidimensional (linhas e colunas ao mesmo tempo).

Exemplo:

.meu-grid {
    display: grid;
    grid-template-columns: 1fr 1fr; /* Duas colunas iguais */
    gap: 15px;
}
Múltiplas Páginas e Responsividade

Conceito: Responsividade é fazer o site se adaptar ao celular usando @media. Múltiplas páginas são arquivos HTML separados ligados por links.

Exemplo:

/* Se a tela for menor que 600px, muda a cor */
@media (max-width: 600px) {
    body {
        background-color: lightgray;
    }
}
