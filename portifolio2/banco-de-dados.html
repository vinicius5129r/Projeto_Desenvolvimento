Conceitos Básicos e SGBD

Dados vs Informação: Dado é um fato bruto (ex: "25"). Informação é o dado com significado (ex: "Idade: 25"). Conhecimento é a aplicação da informação.

SGBD: Sistema Gerenciador de Banco de Dados. É o software que gerencia os dados (ex: MySQL, PostgreSQL, Oracle).

Modelagem: MER, DER e Cardinalidade

MER (Modelo Entidade Relacionamento): É a ideia teórica de como as coisas se conectam.

DER (Diagrama): É o desenho visual dessa ideia (caixinhas e linhas).

Cardinalidade: Define como as tabelas se relacionam:

  • 1:1 (Um para Um) - Ex: Uma pessoa tem um CPF.
  • 1:N (Um para Muitos) - Ex: Um cliente faz vários pedidos.
  • N:M (Muitos para Muitos) - Ex: Vários alunos cursam várias disciplinas.
Normalização (As 3 Formas Normais)

Conceito: Regras para evitar repetição de dados e inconsistências.

  • 1FN: Os dados devem ser atômicos (não pode ter múltiplos valores na mesma célula).
  • 2FN: Estar na 1FN e todos os atributos devem depender de TODA a chave primária.
  • 3FN: Estar na 2FN e nenhum atributo pode depender de outro atributo que não seja a chave primária.
SQL - DDL (Definição de Dados e Constraints)

Conceito: Comandos para criar e alterar a ESTRUTURA do banco (Tabelas, Colunas, Índices e Restrições).

Constraints (Restrições):

  • PRIMARY KEY (PK): Chave primária, identificador único.
  • FOREIGN KEY (FK): Chave estrangeira, garante integridade referencial.
  • UNIQUE: Garante que o valor não se repita na coluna.
  • AUTO_INCREMENT: Gera números sequenciais automaticamente.

Exemplos (CREATE, ALTER, DROP, INDEX):

-- Criar Banco e Usar
CREATE DATABASE locadora;
USE locadora;

-- Criar tabela com Constraints
CREATE TABLE cliente (
    clie_codigo INT AUTO_INCREMENT,
    clie_nome VARCHAR(100) NOT NULL,
    clie_cpf VARCHAR(14) UNIQUE,
    CONSTRAINT pk_cliente PRIMARY KEY (clie_codigo)
);

-- Alterar tabela (Adicionar, Modificar, Excluir colunas)
ALTER TABLE cliente ADD clie_celular VARCHAR(15);
ALTER TABLE cliente MODIFY clie_celular VARCHAR(20);
ALTER TABLE cliente DROP clie_celular;

-- Adicionar Chave Estrangeira via ALTER
ALTER TABLE titulo ADD CONSTRAINT fk_titulo_categoria 
FOREIGN KEY (cate_codigo) REFERENCES categoria(cate_codigo);

-- Criar Índice para buscas mais rápidas
CREATE INDEX ix_cliente_nome ON cliente (clie_nome);

SQL - DML (Manipulação de Dados)

Conceito: Comandos para inserir, atualizar e excluir DADOS nas tabelas.

Exemplos (INSERT, UPDATE, DELETE):

-- Inserir um dado (informando colunas)
INSERT INTO filme (film_titulo, film_ano) VALUES ('THE BATMAN', 2022);

-- Inserir múltiplos dados de uma vez
INSERT INTO exibicao (cine_codigo, film_codigo) VALUES 
(1, 1), (1, 2), (2, 3);

-- Atualizar dados (Sempre use WHERE!)
UPDATE cinema 
SET cine_cidade = 'Manaus', cine_uf = 'AM' 
WHERE cine_codigo = 1;

-- Excluir dados (Sempre use WHERE!)
DELETE FROM locacao 
WHERE film_codigo = 21;
SQL - DQL (Consultas e Filtros Avançados)

Conceito: O comando SELECT recupera dados. Podemos usar operadores lógicos (AND, OR, NOT) e relacionais (=, >, <, !=).

Filtros Especiais:

  • IN / NOT IN: Busca valores dentro de uma lista específica.
  • BETWEEN: Busca valores dentro de um intervalo.
  • LIKE: Busca partes de uma string (% para vários caracteres, _ para um caractere).
  • IS NULL / IS NOT NULL: Testa a ausência de valor.
  • DISTINCT: Remove resultados repetidos.
  • LIMIT / OFFSET: Limita a quantidade de linhas e diz de onde começar a ler.
  • ORDER BY: Ordena o resultado (ASC para crescente, DESC para decrescente).

Exemplos:

-- Uso do IN e DISTINCT
SELECT DISTINCT elei_zona FROM eleitor 
WHERE elei_nome IN ('PEDRO', 'MARIA');

-- Uso do LIKE (Nomes que começam com M)
SELECT func_nome FROM funcionario 
WHERE func_nome LIKE 'M%';

-- Uso do BETWEEN e IS NOT NULL
SELECT * FROM cliente 
WHERE clie_dt_cadastro BETWEEN '2022-01-01' AND '2022-12-31'
AND clie_foto IS NOT NULL;

-- Paginação com LIMIT e OFFSET (Pega 5 registros pulando os 3 primeiros)
SELECT * FROM candidato 
ORDER BY cand_numero DESC 
LIMIT 5 OFFSET 3;
SQL - DQL (Funções de Agregação e Agrupamento)

Conceito: Funções que realizam cálculos em um conjunto de resultados. O GROUP BY agrupa esses resultados, e o HAVING filtra esses grupos.

  • COUNT: Conta o número de linhas.
  • SUM: Soma os valores numéricos.
  • MAX / MIN: Retorna o maior / menor valor.
  • AVG: Calcula a média aritmética.

Exemplos:

-- Funções matemáticas básicas
SELECT 
    COUNT(*) AS "Qtd Candidatos",
    MAX(cand_numero) AS "Maior Número",
    AVG(cand_numero) AS "Média"
FROM candidato;

-- Agrupando dados (GROUP BY) e filtrando o grupo (HAVING)
SELECT part_numero, COUNT(*) AS "Qtd de Candidatos" 
FROM candidato 
GROUP BY part_numero 
HAVING COUNT(*) > 5 
ORDER BY part_numero;
SQL - DQL (Funções de Strings)

Conceito: Funções nativas para manipular textos (caracteres) direto no banco de dados.

Principais Funções:

-- CONCAT: Junta textos
SELECT CONCAT('Nome: ', elei_nome, ' - Zona: ', elei_zona) FROM eleitor;

-- CHAR_LENGTH: Conta a quantidade de caracteres
SELECT CHAR_LENGTH('Rondônia');

-- UPPER / LOWER: Maiúsculas e Minúsculas
SELECT UPPER('instituto'), LOWER('FEDERAL');

-- TRIM / LTRIM / RTRIM: Remove espaços em branco
SELECT TRIM('   IFRO   ');

-- REPLACE: Substitui uma palavra por outra
SELECT REPLACE('GUAJARÁ-MIRIM', 'MIRIM', 'MIRIM/RO');

-- SUBSTR: Extrai um pedaço do texto (A partir da pos 11, pega 5 letras)
SELECT SUBSTR('INSTITUTO FEDERAL', 11, 5);
SQL - DQL (Funções de Datas)

Conceito: Funções para manipular, formatar e fazer cálculos com datas e horas.

Principais Funções:

-- CURDATE() e NOW(): Data atual / Data e Hora atual
SELECT CURDATE(), NOW();

-- Extrair partes da data
SELECT DAY(CURDATE()), MONTH(CURDATE()), YEAR(CURDATE());

-- DATE_ADD / DATE_SUB: Somar ou subtrair dias/meses/anos
SELECT DATE_ADD('2022-01-01', INTERVAL 150 DAY);
SELECT DATE_SUB(CURDATE(), INTERVAL 2 MONTH);

-- DATEDIFF: Diferença de dias entre duas datas
SELECT DATEDIFF('2022-03-14', '2022-01-14');

-- DATE_FORMAT: Formatar a data para o padrão brasileiro
SELECT DATE_FORMAT(CURDATE(), '%d/%m/%Y') AS "Data Formatada";
SELECT DATE_FORMAT(NOW(), '%d/%m/%Y %H:%i:%s');
