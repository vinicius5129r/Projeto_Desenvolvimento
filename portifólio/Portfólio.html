Programação Orientada a Objetos (POO)

Resumo: Paradigma de programação focado em representar o mundo real através de Objetos, Classes e seus relacionamentos.

Teoria, Estruturada vs POO e Variáveis vs Objetos

Conceito: Na programação estruturada, o código é uma sequência de funções (ações). Na POO, o código é um conjunto de Objetos que interagem entre si. Variáveis comuns guardam apenas um valor (ex: int idade = 20;). Objetos guardam Atributos (características) e Métodos (ações/comportamentos) juntos.

Pilares da POO

Conceito: A base da POO se resume em 4 regras fundamentais:

  • Abstração: Pegar algo do mundo real e trazer só o que importa para o código.
  • Encapsulamento: Proteger os dados, escondendo o que não precisa ser visto de fora.
  • Herança: Uma classe "filha" herda características de uma classe "mãe".
  • Polimorfismo: Objetos diferentes podem responder ao mesmo comando de formas diferentes.
Classe Vazia e Atributos

Conceito: A Classe é o molde (a planta da casa). O Objeto é a casa construída. Atributos são as características desse molde.

Exemplo:

// Criando a classe (O Molde)
public class Carro {
    // Atributos (Características)
    String cor;
    String modelo;
    int ano;
}
Métodos (Funções) e Construtor

Conceito: Métodos são as ações que o objeto faz. O Construtor é um método especial chamado automaticamente quando o objeto nasce (é instanciado com new).

Exemplo:

public class Carro {
    String modelo;

    // Método Construtor (Tem o mesmo nome da classe)
    public Carro(String modeloEscolhido) {
        this.modelo = modeloEscolhido;
    }

    // Método comum (Ação)
    public void acelerar() {
        System.out.println("Vrum vrum!");
    }
}

// Criando o objeto na prática:
Carro meuCarro = new Carro("Fusca");
meuCarro.acelerar();
Encapsulamento, Getters e Setters

Conceito: Para proteger os dados (Encapsulamento), deixamos os atributos como private (privados). Para acessá-los ou alterá-los de forma segura, usamos métodos públicos chamados Get (pegar) e Set (alterar).

Exemplo:

public class ContaBancaria {
    // Privado: Ninguém de fora mexe direto aqui
    private double saldo;

    // Setter: Regra para alterar o saldo
    public void setSaldo(double valor) {
        if(valor > 0) {
            this.saldo = valor;
        }
    }

    // Getter: Regra para ver o saldo
    public double getSaldo() {
        return this.saldo;
    }
}
Herança

Conceito: Permite criar uma nova classe aproveitando o código de uma classe que já existe. Usa-se a palavra extends.

Exemplo:

// Classe Mãe
public class Animal {
    public void comer() {
        System.out.println("Comendo...");
    }
}

// Classe Filha (Herda de Animal)
public class Cachorro extends Animal {
    public void latir() {
        System.out.println("Au au!");
    }
}
Polimorfismo

Conceito: "Muitas formas". É quando a classe filha reescreve (sobrescreve) um método da classe mãe para fazer a mesma ação, mas do seu próprio jeito.

Exemplo:

public class Animal {
    public void fazerSom() {
        System.out.println("Som de animal");
    }
}

public class Gato extends Animal {
    // Reescrevendo o método da mãe
    @Override
    public void fazerSom() {
        System.out.println("Miau!");
    }
}

Banco de Dados I

Resumo: Fundamentos de armazenamento de dados, modelagem (MER/DER), normalização e aprofundamento em comandos SQL (DDL, DML, DQL e Funções).

Conceitos Básicos e SGBD

Dados vs Informação: Dado é um fato bruto (ex: "25"). Informação é o dado com significado (ex: "Idade: 25"). Conhecimento é a aplicação da informação.

SGBD: Sistema Gerenciador de Banco de Dados. É o software que gerencia os dados (ex: MySQL, PostgreSQL, Oracle).

Modelagem: MER, DER e Cardinalidade

MER (Modelo Entidade Relacionamento): É a ideia teórica de como as coisas se conectam.

DER (Diagrama): É o desenho visual dessa ideia (caixinhas e linhas).

Cardinalidade: Define como as tabelas se relacionam:

  • 1:1 (Um para Um) - Ex: Uma pessoa tem um CPF.
  • 1:N (Um para Muitos) - Ex: Um cliente faz vários pedidos.
  • N:M (Muitos para Muitos) - Ex: Vários alunos cursam várias disciplinas.
Normalização (As 3 Formas Normais)

Conceito: Regras para evitar repetição de dados e inconsistências.

  • 1FN: Os dados devem ser atômicos (não pode ter múltiplos valores na mesma célula, ex: dois telefones juntos).
  • 2FN: Estar na 1FN e todos os atributos devem depender de TODA a chave primária.
  • 3FN: Estar na 2FN e nenhum atributo pode depender de outro atributo que não seja a chave primária (sem dependência transitiva).
SQL - DDL (Definição de Dados e Constraints)

Conceito: Comandos para criar e alterar a ESTRUTURA do banco (Tabelas, Colunas, Índices e Restrições).

Constraints (Restrições):

  • PRIMARY KEY (PK): Chave primária, identificador único.
  • FOREIGN KEY (FK): Chave estrangeira, garante integridade referencial.
  • UNIQUE: Garante que o valor não se repita na coluna.
  • AUTO_INCREMENT: Gera números sequenciais automaticamente.

Exemplos (CREATE, ALTER, DROP, INDEX):

-- Criar Banco e Usar
CREATE DATABASE locadora;
USE locadora;

-- Criar tabela com Constraints
CREATE TABLE cliente (
    clie_codigo INT AUTO_INCREMENT,
    clie_nome VARCHAR(100) NOT NULL,
    clie_cpf VARCHAR(14) UNIQUE,
    CONSTRAINT pk_cliente PRIMARY KEY (clie_codigo)
);

-- Alterar tabela (Adicionar, Modificar, Excluir colunas)
ALTER TABLE cliente ADD clie_celular VARCHAR(15);
ALTER TABLE cliente MODIFY clie_celular VARCHAR(20);
ALTER TABLE cliente DROP clie_celular;

-- Adicionar Chave Estrangeira via ALTER
ALTER TABLE titulo ADD CONSTRAINT fk_titulo_categoria 
FOREIGN KEY (cate_codigo) REFERENCES categoria(cate_codigo);

-- Criar Índice para buscas mais rápidas
CREATE INDEX ix_cliente_nome ON cliente (clie_nome);
SQL - DML (Manipulação de Dados)

Conceito: Comandos para inserir, atualizar e excluir DADOS nas tabelas.

Exemplos (INSERT, UPDATE, DELETE):

-- Inserir um dado (informando colunas)

-- Inserir múltiplos dados de uma vez

SQL - DQL (Consultas e Filtros Avançados)

Conceito: O comando SELECT recupera dados. Podemos usar operadores lógicos (AND, OR, NOT) e relacionais (=, >, <, !=).

Filtros Especiais:

  • IN / NOT IN: Busca valores dentro de uma lista específica.
  • BETWEEN: Busca valores dentro de um intervalo.
  • LIKE: Busca partes de uma string (% para vários caracteres, _ para um caractere).
  • IS NULL / IS NOT NULL: Testa a ausência de valor.
  • DISTINCT: Remove resultados repetidos.
  • LIMIT / OFFSET: Limita a quantidade de linhas e diz de onde começar a ler.
  • ORDER BY: Ordena o resultado (ASC para crescente, DESC para decrescente).

Exemplos:

-- Uso do IN e DISTINCT
SELECT DISTINCT elei_zona FROM eleitor 
WHERE elei_nome IN ('PEDRO', 'MARIA');

-- Uso do LIKE (Nomes que começam com M)
SELECT func_nome FROM funcionario 
WHERE func_nome LIKE 'M%';

-- Uso do BETWEEN e IS NOT NULL
SELECT * FROM cliente 
WHERE clie_dt_cadastro BETWEEN '2022-01-01' AND '2022-12-31'
AND clie_foto IS NOT NULL;

-- Paginação com LIMIT e OFFSET (Pega 5 registros pulando os 3 primeiros)
SELECT * FROM candidato 
ORDER BY cand_numero DESC 
LIMIT 5 OFFSET 3;
SQL - DQL (Funções de Agregação e Agrupamento)

Conceito: Funções que realizam cálculos em um conjunto de resultados. O GROUP BY agrupa esses resultados, e o HAVING filtra esses grupos.

  • COUNT: Conta o número de linhas.
  • SUM: Soma os valores numéricos.
  • MAX / MIN: Retorna o maior / menor valor.
  • AVG: Calcula a média aritmética.

Exemplos:

-- Funções matemáticas básicas
SELECT 
    COUNT(*) AS "Qtd Candidatos",
    MAX(cand_numero) AS "Maior Número",
    AVG(cand_numero) AS "Média"
FROM candidato;

-- Agrupando dados (GROUP BY) e filtrando o grupo (HAVING)
SELECT part_numero, COUNT(*) AS "Qtd de Candidatos" 
FROM candidato 
GROUP BY part_numero 
HAVING COUNT(*) > 5 
ORDER BY part_numero;
SQL - DQL (Funções de Strings)

Conceito: Funções nativas para manipular textos (caracteres) direto no banco de dados.

Principais Funções:

-- CONCAT: Junta textos
SELECT CONCAT('Nome: ', elei_nome, ' - Zona: ', elei_zona) FROM eleitor;

-- CHAR_LENGTH: Conta a quantidade de caracteres
SELECT CHAR_LENGTH('Rondônia');

-- UPPER / LOWER: Maiúsculas e Minúsculas
SELECT UPPER('instituto'), LOWER('FEDERAL');

-- TRIM / LTRIM / RTRIM: Remove espaços em branco
SELECT TRIM('   IFRO   ');

-- REPLACE: Substitui uma palavra por outra
SELECT REPLACE('GUAJARÁ-MIRIM', 'MIRIM', 'MIRIM/RO');

-- SUBSTR: Extrai um pedaço do texto (A partir da pos 11, pega 5 letras)
SELECT SUBSTR('INSTITUTO FEDERAL', 11, 5);
SQL - DQL (Funções de Datas)

Conceito: Funções para manipular, formatar e fazer cálculos com datas e horas.

Principais Funções:

-- CURDATE() e NOW(): Data atual / Data e Hora atual
SELECT CURDATE(), NOW();

-- Extrair partes da data
SELECT DAY(CURDATE()), MONTH(CURDATE()), YEAR(CURDATE());

-- DATE_ADD / DATE_SUB: Somar ou subtrair dias/meses/anos
SELECT DATE_ADD('2022-01-01', INTERVAL 150 DAY);
SELECT DATE_SUB(CURDATE(), INTERVAL 2 MONTH);

-- DATEDIFF: Diferença de dias entre duas datas
SELECT DATEDIFF('2022-03-14', '2022-01-14');

-- DATE_FORMAT: Formatar a data para o padrão brasileiro
SELECT DATE_FORMAT(CURDATE(), '%d/%m/%Y') AS "Data Formatada";
SELECT DATE_FORMAT(NOW(), '%d/%m/%Y %H:%i:%s');

Estruturas de Repetição (Enquanto / Repita)

Conceito: Usado para executar um bloco de código várias vezes sem precisar reescrever.

// REPITA (Teste no fim)
contador <- 1
repita
   escreval(contador)
   contador <- contador + 1
ate (contador > 5)

Linguagem de Programação

Variáveis, Escopo e Operadores

Tipos Primitivos: int (inteiro), double (decimal), boolean (verdadeiro/falso), char (um caractere).

Escopo (Global vs Local): Variável local só existe dentro do bloco onde foi criada (ex: dentro de um método). Variável global (atributo de classe) pode ser vista por toda a classe.

Operadores: Aritméticos (+ - * / %), Relacionais (== != > < >= <=) e Lógicos (&& para E, || para OU).

Seleção: if/else (Se/Senão) e switch/case (Escolha/Caso).

Repetição: for (Para), while (Enquanto) e do/while (Faça/Enquanto).

Exemplo (Java):

    System.out.println("Aprovado");

    System.out.println("Reprovado");
}

// Laço FOR (Início; Condição; Incremento)
for (int i = 1; i <= 5; i++) {
    System.out.println("Contagem: " + i);

Funções e Passagem de Parâmetros

Funções/Procedimentos: Em Java chamamos de Métodos. Se retorna algo, tem um tipo (ex: int). Se não retorna, usamos void.

Passagem por Valor vs Referência: No Java, TUDO é passado por valor (uma cópia). Porém, quando passamos um Objeto, o valor copiado é a "referência" (o controle remoto) dele. Se alterar o objeto dentro do método, altera o original.

Exemplo (Java):

// Método que soma e RETORNA um valor
public int somar(int a, int b) {
    return a + b;
}

// Método VOID (só executa, não retorna nada)
public void imprimirNome(String nome) {
    System.out.println("Nome: " + nome);
}
Collections, Autoboxing e Ordenação

Collections: Diferente do Vetor, listas como ArrayList e LinkedList têm tamanho DINÂMICO (crescem sozinhas).

Autoboxing/Unboxing: É a conversão automática que o Java faz entre tipos primitivos (int) e suas Classes (Integer), pois Coleções só aceitam Objetos.

Exemplo (Java):

import java.util.ArrayList;
import java.util.Collections;

public class TesteLista {
    public static void main(String[] args) {
        // Criando uma Lista Dinâmica
        ArrayList<String> nomes = new ArrayList<>();
        
        nomes.add("Zeca");
        nomes.add("Ana");
        nomes.add("Pedro");

        // Ordenando a lista em ordem alfabética
        Collections.sort(nomes);
        
        System.out.println(nomes); // [Ana, Pedro, Zeca]
    }
}

Redes de Computadores I

Resumo: Fundamentos de infraestrutura, equipamentos, topologias, cabeamento estruturado e os modelos de comunicação OSI e TCP/IP.

Classificação e Topologias de Rede

Classificação por Abrangência (Tamanho):

  • PAN: Personal Area Network (Bluetooth, rede pessoal).
  • LAN: Local Area Network (Rede local, uma casa ou prédio).
  • MAN: Metropolitan Area Network (Rede metropolitana, interliga bairros).
  • WAN: Wide Area Network (Rede de longa distância, países, a própria Internet).

Topologias Físicas (Desenho da rede):

  • Ponto a Ponto: Dois PCs ligados diretamente.
  • Estrela: Todos ligados a um equipamento central (Switch). É a mais usada hoje.
  • Barramento: Todos no mesmo cabo (antigo, se o cabo quebra, a rede cai).
  • Anel: Sinais andam em círculo (Token Ring).
  • Malha (Mesh): Todos conectados com todos (alta redundância).
Transmissão, Meios e Hardware

Modos de Transmissão:

  • Simplex: Só vai (Ex: Rádio, TV).
  • Half-Duplex: Vai e volta, mas um de cada vez (Ex: Walkie-talkie).
  • Full-Duplex: Vai e volta ao mesmo tempo (Ex: Telefone, redes modernas).

Meios de Transmissão: Guiados (Cabos de Cobre, Fibra Óptica) e Não Guiados (Wi-Fi, Satélite, Rádio).

Hardware de Rede:

  • Placa de Rede (NIC): Onde o cabo entra. Tem o endereço físico (MAC).
  • Hub: "Burro". Recebe a informação e grita para todos (Gera lentidão/colisão).
  • Switch: "Inteligente". Sabe quem é quem pelo MAC Address e manda só para o PC certo.
  • Roteador: Conecta redes DIFERENTES (Ex: sua LAN com a WAN/Internet) usando o endereço IP.
Modelos de Camadas: OSI e TCP/IP

Conceito: Dividir a comunicação em "fatias" para facilitar a criação de regras (protocolos). O OSI é o modelo teórico (7 camadas). O TCP/IP é o modelo prático usado na Internet (4 ou 5 camadas).

As Camadas (Visão Prática):

  • Física: O cabo, o sinal elétrico, a luz da fibra, o Wi-Fi. (Bits).
  • Enlace: Comunicação local. Usa o Switch e o endereço MAC. (Quadros/Frames).
  • Rede: Roteamento. Acha o melhor caminho. Usa o Roteador e o endereço IP. (Pacotes).
  • Transporte: Garante a entrega. Protocolo TCP (garante entrega, mais lento) ou UDP (não garante, mas é rápido, ex: vídeos/jogos). (Segmentos).
  • Aplicação: O que o usuário vê. Protocolos: HTTP (Sites), DNS (Nomes), FTP (Arquivos).
Camada de Rede: Endereçamento IP

IPv4 vs IPv6: IPv4 (32 bits, ex: 192.168.1.10) está acabando. IPv6 (128 bits, letras e números) é o futuro.

IP Público vs Privado:

  • Público: Único no mundo (fornecido pelo seu provedor de internet).
  • Privado: Usado dentro da sua LAN (Ex: 192.168.x.x ou 10.x.x.x). Não navega direto na internet sem o roteador (NAT).

Dinâmico vs Estático: Dinâmico muda (entregue pelo servidor DHCP). Estático é fixado manualmente (usado em servidores e impressoras).

Exemplo de Comando (Terminal):

# Descobrir seu IP no Windows
ipconfig

# Testar se um site ou PC está respondendo na rede
ping www.google.com
Cabeamento Estruturado e Normas

Conceito: Organizar os cabos de forma padronizada para evitar bagunça, facilitar manutenção e suportar tecnologias futuras.

Componentes: Cabos UTP (Par trançado), Conectores RJ-45, Patch Panels (painel de manobra), Racks (armários de telecom).

Normas (TIA/EIA-568): Define a ordem das cores nos cabos de rede.

Exemplo (Padrão T568A vs T568B):

// Padrão T568A (Cores da esquerda para a direita)
1. Branco/Verde | 2. Verde | 3. Branco/Laranja | 4. Azul 
5. Branco/Azul  | 6. Laranja | 7. Branco/Marrom | 8. Marrom

// Padrão T568B (Mais usado no Brasil)
1. Branco/Laranja | 2. Laranja | 3. Branco/Verde | 4. Azul 
5. Branco/Azul    | 6. Verde   | 7. Branco/Marrom | 8. Marrom
Instalações Elétricas e Projetos de Rede

Instalações Elétricas: Redes de dados são sensíveis. É obrigatório ter um bom Aterramento (fio terra) para evitar queima de equipamentos e usar Nobreaks (UPS) para manter os switches/servidores ligados se a luz cair.

Projeto de Redes:

  1. Levantamento: O que o cliente precisa? Quantos PCs?
  2. Topologia Lógica e Física: Desenhar onde passam os cabos e quais serão os IPs.
  3. Documentação: Planta baixa, identificação dos cabos (etiquetas) e relatórios de certificação (testes com aparelhos Fluke).
